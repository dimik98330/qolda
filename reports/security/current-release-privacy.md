**Решение для капитана:** в проверенном текущем дереве Git нет находок по перечисленным ниже признакам. Это не разрешение на открытие репозитория: его история сохраняет прежнее значение поля с машинным путём. Для публикации нужна отдельная проверка и решение капитана. APK проверен как файл, не как запущенное приложение.

Квитанция на ПК Димаса должна использовать SHA его собственных файлов, без сырых клипов, покадровых данных, полных логов и ключей подписи. Наличие файла, запуск, полный анализ и автономность — четыре разные отметки.
